PROJECT 001 · EMAIL SECURITY

Phishing Email
Analysis Report

A simulated phishing email investigation focused on understanding how a SOC analyst can assess a suspicious message reported by an employee.

PROJECT OUTCOMEStructured investigation report with evidence, analysis, and a final verdict
01 / WHAT & WHY

Investigate the message

The project explores how a SOC analyst might investigate an employee-reported suspicious email and determine whether it is malicious.

02 / OBJECTIVE

Find and document indicators

Analyze a simulated phishing email, identify indicators of compromise (IOCs), and document the investigation and conclusion.

03 / TOOLS & METHODS

Follow the evidence

  • Email header analysis
  • VirusTotal
  • CyberChef
  • URL and domain analysis
04 / ACTIONS TAKEN

Review, extract, record

Reviewed a simulated email, analyzed its headers and URLs/domains, used available tools to examine indicators, and organized observations in a report.

05 / SKILLS PRACTICED

Investigation habits

  • Analyzing suspicious email
  • Identifying and extracting IOCs
  • Using available analysis tools
  • Clearly documenting security findings
06 / REAL-WORLD RELEVANCE

Useful SOC workflow

Suspicious email triage and clear documentation are relevant to security operations, where analysts need to assess reported messages and communicate findings.
